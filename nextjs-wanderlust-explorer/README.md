# Wanderlust Explorer

A travel-experience discovery app built with Next.js App Router, React, TypeScript, and Tailwind CSS. Browse the local catalogue, search and filter experiences, view details, and manage in-memory favorites.

## Getting Started

Run these commands from the `nextjs-wanderlust-explorer` directory:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```

Favorites are held in memory and reset when the application session ends. The app does not use a backend or external data API.
